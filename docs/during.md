# During the Workshop

[← Home](index.md)

Keep this page open as your **home base** during the day.

## How each block works

1. **Teach (10–20 min):** your instructor introduces the concept and demos it once.
2. **Lab (15–35 min):** you do it yourself on the CivicPermit repo.
3. **Debrief (5 min):** we compare results and answer questions.

Every lab advances the **same** feature story, so if you fall behind you can catch up by
copying the reference files from [`solutions/`](../solutions/README.md) — ask your instructor.

## The story, at a glance

```
Issue  →  Branch  →  Commit  →  Pull Request  →  Review  →  Workflow  →  Merge  →  Release
```

You are implementing:
**"Add the ability to schedule an inspection for an existing permit."**

## Ground rules

- **Ask early.** If you're stuck for more than a couple of minutes, raise your hand.
- **Green means go.** After each code change, run `dotnet test` before moving on.
- **Small steps.** Commit often with clear messages — you'll thank yourself in review.
