# 6-Hour Agenda

[← Home](index.md)

This workshop is designed as a single day with two breaks and a lunch. Times are a guide;
your instructor will adjust to the room. Every module pairs a short teach with a hands-on
lab that advances the **same** feature story.

| Time | Block | Module | Lab |
| ---- | ----- | ------ | --- |
| 0:00–0:30 | Welcome & setup | [Module 0](modules/00-welcome-and-setup.md) | [Lab 00](labs/lab-00-setup.md) |
| 0:30–1:15 | The workflow & Issues | [Module 1](modules/01-github-workflow-and-issues.md) | [Lab 01](labs/lab-01-open-the-issue.md) |
| 1:15–2:00 | Branching & Commits | [Module 2](modules/02-branching-and-commits.md) | [Lab 02](labs/lab-02-branch-and-first-commit.md) |
| 2:00–2:15 | ☕ Break | — | — |
| 2:15–3:00 | Pull Requests & Review | [Module 3](modules/03-pull-requests-and-review.md) | [Lab 03](labs/lab-03-implement-endpoint-and-test.md), [Lab 04](labs/lab-04-open-pull-request.md) |
| 3:00–3:30 | Review in practice | [Module 3](modules/03-pull-requests-and-review.md) | [Lab 05](labs/lab-05-review-and-address-feedback.md) |

## The story you'll build

```
Issue  →  Branch  →  Commit  →  Pull Request  →  Review  →  Workflow  →  Merge  →  Release
Lab 01     Lab 02     Lab 03       Lab 04         Lab 05     Lab 06      Lab 07     Lab 08
```

All of it delivers one feature to CivicPermit:
**"Add the ability to schedule an inspection for an existing permit."**
